# Project Nexus: AI Engineering Roadmap

## Milestone 0 — Foundations of Modern LLMs
**Objective:** Understand how today's language models actually work.

## Milestone 1 — Build a Minimal AI Chat
**Objective:** Create the first working version of Project Nexus.

### Theory
* API Communication
* Streaming Responses
* Chat Message Structure
* System Prompts
* Prompt Engineering

### Mini Features
* Chat interface
* Streaming responses
* Markdown rendering
* Conversation history
* Syntax highlighting

**Deliverable:** Version 1 of the AI Workspace.
