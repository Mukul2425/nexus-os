## LANGUAGE MODEL

- # What is language model?
-> Language model is basically a machine learning model , where the model predicts the next word, it could be statistical or neural network based primarily used for computers/ machines to understand human language.

-> **Training vs Inference** -> Training primarily means learning from the existing knowledge or database while Inference means applying the learned knowledge to make real time predictions.

-> Popular ways for next token predictions lies in NLP like n-grams or encoder/ decoder models. SELF SUPERVISED learning by predicting the next tokens on statistics. 
Topics like Auto Regression, Tokenization, probabilty scoring(Prob. Distribution).
->**Auto Regression** -> It is the way encoder / decoder models work primarily the RNN's , they work like whenever a token is produced it is added to the next sequence of input which becomes the input to the model.
